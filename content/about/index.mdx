## How I work

Since 2024 I build with AI agents every day. I plan, review and decide. The agents write most of the code, run the checks and tell me what broke. That made me care more about the plan, the tests and the review, not less. This site is one result: built with Claude Code in eight days, with a sky made from real stars.
