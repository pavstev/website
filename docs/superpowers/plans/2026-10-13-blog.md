# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/blog` (a moon-orbit index over the live sky) and two MDX posts, built and published by `pnpm build`.

**Architecture:** Posts are MDX in `content/blog/<slug>/`, compiled by `@mdx-js/mdx` `evaluate()` inside server components at build time. A prebuild script makes the images, share images, Markdown copies and a build marker. The sky component gains an eclipse selector, a preset event and a header mode; a client island draws the moons.

**Tech Stack:** Next.js 16.3.8 (App Router, `output: "export"`, Turbopack), React 19.3, TypeScript 6 strict, Tailwind v4, zod 4, `@mdx-js/mdx` 3, `@shikijs/rehype` 4, sharp 0.35, `next/og`, raw WebGL2, Cloudflare Workers static assets, Node 24 type stripping for scripts and tests.

**Spec:** `docs/superpowers/specs/2026-10-13-blog-design.md` (read it first; it holds every owner decision).

## Global Constraints

- Repo rules in `CLAUDE.md`: no comments or JSDoc in source, no `eslint-disable`, no `any`, no `!`, no hex or hsl outside `globals.css` and `src/lib/theme.ts`, every UI string in `src/lib/i18n.ts`, Tailwind paren syntax, explicit return types on exports, `import { type Foo }`, kebab-case files, one component per file in `src/components/`.
- Code that scripts or tests load (`scripts/*.ts`, `src/lib/blog/*.ts` except `render.tsx`, `src/lib/sky-preset.ts`) uses relative imports with the `.ts` extension, no `@/` alias and no JSX, because Node runs it with type stripping.
- Copy rules for every shipped string and both posts: no em dashes, no taglines, no eyebrow labels, no "01 —" numbering, no dash-bullet lists in UI.
- No dark boxes, halos or text shadows behind text over the sky; text over the sky uses `text-sky` with a probe target.
- WCAG 2.1 AA, plus WCAG 2.2.2: anything that moves for more than 5 s stops with the pause button (`isSceneHeld()` / `stillQuery()`).
- Home page: nothing visible changes except the new Blog button.
- Cloudflare: only the owner's main account; never the one `CLAUDE.md` rules out. Never run `wrangler deploy`, `wrangler preview` or `pnpm deploy` by hand.
- Local builds use `CV_SNAPSHOT=1` (no CV token in worktrees); `GITHUB_TOKEN` comes from `gh auth token` automatically.
- Each lane works in its own worktree `/Users/pavstev/work/website-blog-<lane>` on branch `blog-<lane>` (made from `blog`), dev server port from the lane table, and makes one commit at the end with `HUSKY=0` after its own checks pass. The full `pnpm check` runs once after the merge into `blog`.

## Review Focus

- A frontmatter mistake (missing field, description over 160 characters, unknown weather) must fail the build with the file path and the field name. Test in Task 1.
- Titles and text with `&`, `<`, quotes or `]]>` must stay intact and safe in RSS, JSON Feed, JSON-LD (`<` escaped as `<` via `serializeJsonLd`) and the share image. Tests in Tasks 1 and 4.
- A `draft: true` post in a production build must appear nowhere: no page, sitemap entry, feed item, `llms.txt` line, Markdown copy, share image or `/mcp` result. Tests in Tasks 1, 3 and 4.
- A long title or a long word on a 320 px phone and at 200% zoom must wrap without horizontal scroll (row titles, post title, moon labels). Checked in Tasks 2 and 6 with the sweep.
- Reduced motion, the pause button, no WebGL2, a software renderer, Save-Data and forced colors on blog pages: moons stand still or fall back to CSS circles, the sky snaps, nothing animates longer than 5 s. Checked in Task 6.
